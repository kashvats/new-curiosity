# Project Overview

This project is a local AI Coding Assistant. It consists of a FastAPI backend and a React frontend. The backend handles local RAG vectors (Qdrant), LLM generation (Ollama), and AST patching. It maintains a secure execution environment, restricting unsafe path traversals and logging.
